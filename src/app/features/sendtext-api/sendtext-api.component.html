SendText Integration Guide

Single endpoint for dispatching SMS, WhatsApp and Voice messages with automatic fallback. Share this page with any third-party application that will integrate.

Endpoint

POST {{ baseUrl }}/sendtext
Content-Typeapplication/x-www-form-urlencoded
Authenticationapikey + secretkey form fields (issued by NetZero). Invalid or missing credentials are rejected
ProcessingAsynchronous. The response confirms queuing, not delivery

Request Parameters (form fields)

FieldRequiredDescription
toUser Required Recipient number(s) with country code, e.g. 8801700000001. For multiple recipients, separate with commas: 8801700000001,8801700000002. Every number receives every tagged message.
messageContent Required The message. Use channel tags (below) to pick channels. Without any tag the whole content is sent as a plain SMS.
apikey Required API key issued by NetZero. Requests with a wrong or missing key are rejected.
secretkey Required Secret key issued by NetZero. Keep it confidential. Use it server-side only, never in client-side code.
callerID Required Sender ID recorded with the request.

Channel Tags

Compose messageContent from one or more [tag::content] blocks. Each tag creates one delivery. Several tags may be combined in a single request.

TagChannelExample
[sms::TEXT] SMS [sms::Your OTP is 123456]
[wp::TEXT] WhatsApp text [wp::Hello, your appointment is confirmed.]
[smswp::TEXT] SMS and WhatsApp (same text) [smswp::Big sale this weekend!]
[wpmedia::TEXT||URL] WhatsApp media (caption + public file URL) [wpmedia::Please review the invoice.||https://example.com/invoice.pdf]
[call::CAMPAIGN_ID] Voice call (pre-configured campaign) [call::due-bill-api]
(no tag) Plain SMS with the full content Hello without any tag

Response

FieldMeaning
Status"0" = accepted  ·  "101" = rejected (invalid/missing credentials or server error)
TextACCEPTD or REJECTD
Message_IDTracking id (GUID) of the queued request
