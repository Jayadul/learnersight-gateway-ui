Worth knowing

  • These keys are the gateway's own. They are not any SMS provider's credentials — rotating a channel's provider keys no longer affects integrator access, and rotating these does not touch any channel.
  • callerID is required on every request and recorded with it, but it plays no part in authentication.
  • Changes apply to the next request. There is no grace period and no second active pair.
  • Rejections caused by these credentials return 101 REJECTD with no Reason field. A rejection that carries a Reason is a message-content problem, not an auth one.
